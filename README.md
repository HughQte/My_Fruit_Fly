# My_Fruit_Fly

This repository contains exploratory, self-education analyses based on publicly available FlyWire data for adult Drosophila brain connectivity.

## Data source
- FlyWire data portal: https://codex.flywire.ai
- Primary publication: Dorkenwald, S. et al. (2024). "Neuronal wiring diagram of an adult brain." Nature. https://doi.org/10.1038/s41586-024-07558-y

## Attribution and data use
These datasets are derived from FlyWire open-access resources. When reusing or adapting any data, code, or figures from this project, please provide attribution to the FlyWire dataset and cite the associated publication above.
